# dittofleet

Tools for easier multi-environment agentic development.

### For agents

- <img src="https://raw.githubusercontent.com/dittofleet/weblab/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**weblab**](https://github.com/dittofleet/weblab): test and explore web apps in a real browser. Drive them, check them, and capture screenshots, video and traces.
- <img src="https://raw.githubusercontent.com/dittofleet/dropcube/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**dropcube**](https://github.com/dittofleet/dropcube): a write-only file drop for agents on remote machines, with private view links for you. Runs on Cloudflare R2 and Workers.
- <img src="https://raw.githubusercontent.com/dittofleet/navi/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**navi**](https://github.com/dittofleet/navi): hey, listen! Notifications on your phone from coding agents, through ntfy.
- <img src="https://raw.githubusercontent.com/dittofleet/whatagain/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**whatagain**](https://github.com/dittofleet/whatagain): a todo list for coding agents, scoped to repos.
- <img src="https://raw.githubusercontent.com/dittofleet/rm-to-trash/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**rm-to-trash**](https://github.com/dittofleet/rm-to-trash): `rm`, but to the Trash, so anything an agent deletes by mistake can be recovered.
- <img src="https://raw.githubusercontent.com/dittofleet/skills/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**skills**](https://github.com/dittofleet/skills): agent skills for multi-environment development.

### For running many environments

- <img src="https://raw.githubusercontent.com/dittofleet/port-pool/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**port-pool**](https://github.com/dittofleet/port-pool): hands out unique ports so you can test several worktrees or copies of a project in parallel.
- <img src="https://raw.githubusercontent.com/dittofleet/lichen/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**lichen**](https://github.com/dittofleet/lichen): keeps dotfiles, configs and agent skills in sync across macOS machines.
- <img src="https://raw.githubusercontent.com/dittofleet/crosstalk/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**crosstalk**](https://github.com/dittofleet/crosstalk): lets the apps on your Macs message each other and share status and settings, through a hub on your own Cloudflare account.
- <img src="https://raw.githubusercontent.com/dittofleet/terrier/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**terrier**](https://github.com/dittofleet/terrier): one registry of your repos, shared by your other tools, so a project registered once shows up in all of them.

### For your Mac

- <img src="https://raw.githubusercontent.com/dittofleet/headroom/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**headroom**](https://github.com/dittofleet/headroom): a menu bar app for your Claude and Codex usage limits.
- <img src="https://raw.githubusercontent.com/dittofleet/figment/main/assets/icon.svg" width="20" height="20" align="top" alt=""> [**figment**](https://github.com/dittofleet/figment): virtual displays of any size, including 4K and HiDPI, for a Mac with no monitor or room for more.
